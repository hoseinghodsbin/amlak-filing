# نرم‌افزار فایلینگ املاک

نرم‌افزار ساده و سبک برای مدیریت فایل‌های ملکی (آژانس املاک)

## دانلود نسخه ویندوز

از بخش [Releases](https://github.com/hoseinghodsbin/amlak-filing/releases) فایل `AmlakFiling.exe` را دانلود کنید.

## امکانات

- ثبت، ویرایش و حذف ملک
- فیلتر و جستجوی پیشرفته
- ذخیره در دیتابیس محلی (SQLite)
- خروجی Excel (CSV)
- رابط کاملاً فارسی

## اجرا از سورس

```bash
pip install customtkinter
python amlak_filing.py
```
